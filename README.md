## Projects

**[Financas-api](https://github.com/rafasx17/Financas-api)** — Personal finance platform, end-to-end  
`FastAPI` `JWT` `SQLAlchemy` `PostgreSQL` `Vanilla JS` `Railway`  
REST API + dashboard served by the same process — no CORS, no separate server. Stateless auth with per-user data isolation, CSV import with auto-detection of Brazilian bank formats (Nubank, Inter, Bradesco), monthly goals with real-time progress. Running in production.

**[Aeroflow](https://github.com/rafasx17/aeroflow)** — Airport ground operations API  
`Java 17` `Spring Boot 4` `Spring Data JPA` `H2`  
State machine that enforces flight status transitions in strict order. Gates auto-release on departure. Business rules live at the domain level — controllers just delegate.

**[URL Shortener](https://github.com/rafasx17/url-shortener)** — URL shortening service  
`FastAPI` `JWT` `PostgreSQL` `Railway`  
Short URL generation with JWT-authenticated management, click tracking and production deploy on Railway.
