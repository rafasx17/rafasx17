## Projetos

**[Finanças API](https://github.com/rafasx17/Financas-api)** — Plataforma completa de finanças pessoais  
`FastAPI` `JWT` `SQLAlchemy` `PostgreSQL` `Vanilla JS` `Docker` `Railway`  
API REST + dashboard servido pelo mesmo processo — sem CORS, sem servidor separado. Autenticação stateless com isolamento de dados por usuário, importação de extrato CSV com detecção automática de formato dos bancos brasileiros (Nubank, Inter, Bradesco), metas mensais com progresso em tempo real. Rodando em produção.

**[Aeroflow](https://github.com/rafasx17/aeroflow)** — API de gerenciamento de operações aeroportuárias  
`Java 17` `Spring Boot 4` `Spring Data JPA` `H2`  
Máquina de estados que impõe transições de status de voo em ordem obrigatória. Portões são liberados automaticamente na decolagem. Regras de negócio vivem na camada de domínio — controllers só delegam.

**[URL Shortener](https://github.com/rafasx17/url-shortener)** — Serviço de encurtamento de URLs  
`FastAPI` `JWT` `PostgreSQL` `Docker` `Railway`  
Geração de URLs curtas com gerenciamento autenticado via JWT, contagem de cliques e deploy em produção no Railway.
